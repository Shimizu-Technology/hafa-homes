# Locations LLC Research

## Overview

Locations LLC is a Hawaii real estate brokerage with a website and mobile app designed specifically for Hawaii homebuyers and sellers.

Website: `locationshawaii.com`

Mobile apps:

- iOS: Locations LLC by Virtual Properties
- Android: Locations LLC by Virtual Properties, Inc.

Their positioning is:

> The real estate app built for Hawaii.

## What Locations does well

Locations is not just a listing app. It combines:

- MLS search
- Local Hawaii-specific filters
- Neighborhood and condo search
- Home valuation
- Market statistics
- Open house discovery
- Saved searches and alerts
- Agent lead routing
- Buyer/seller education
- Local market reports

## Core app features

### Search

Users can search by:

- Island
- Neighborhood
- Condominium/building name
- Address or landmark
- GPS/current location
- Drawn custom map area
- MLS number
- Property type
- Price
- Beds/baths
- Keywords

### Local Hawaii-specific filters

Important differentiators:

- Fee simple vs leasehold land tenure
- Condo/building search
- Maintenance fees
- Legal short-term rental condo content
- Military base proximity content
- Neighborhood-specific market data

### Listing pages

Listing details include:

- Photos
- Price
- Address/location
- Beds/baths
- Property details
- Parking
- Year built
- Maintenance fees
- Pricing/sales history
- Open house info
- Agent contact CTAs

### Saved searches and alerts

Users can save listings and searches, then receive alerts for:

- New matching listings
- Price drops
- Sold/status changes

### Open houses

Users can find open houses, add them to calendars, and get directions.

### Agent connection

The app is connected to the Locations brokerage model. Users can select or find a Locations agent, request information, and schedule showings.

### Home valuation

Locations has a home valuation product marketed as more accurate than Zillow because it uses Hawaii-specific neighborhood boundaries and data.

### Market reports

Locations publishes monthly and quarterly market reports by island/region. They position their data and research as a competitive advantage.

## Lessons for Hafa Homes

Hafa Homes should borrow the strategy, not copy the exact feature set.

Key lesson:

> The value is hyperlocal real estate context layered on top of listings.

For Guam, equivalent local value includes:

- Military relocation
- Base commute
- Village lifestyle
- Rental availability
- Pet-friendly/furnished/OHA-friendly rentals
- Typhoon readiness features
- Property manager/landlord workflows
- Local market snapshots
