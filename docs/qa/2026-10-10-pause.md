# Hafa Homes pause acceptance

## Context and scope

Agent-executed affected-flow QA. Base main `6b8ce934`; production API `e6141c16342465fcf073527a302f83f902777fac`. Hafa Homes is a public Guam housing demo with brokerage-scoped listings, anonymous leads, signed-in saved homes, CRM, notification reconciliation, and account deletion. Leon requested a temporary pause to avoid ongoing runtime costs. Source: current-product-truth, the October 10 hosting audit, and production checks. The original local checkout has unresolved unrelated changes and remains untouched; this work uses `codex/hafa-homes-pause-20261010` in a separate worktree.

Required acceptance: a useful pause notice on public and direct app routes; no app/API/auth initialization during pause; support and existing privacy policy remain available; finite failure/retry behavior; explicit resume path; Render suspended only after the deployed notice and no outstanding durable work are confirmed. Native release changes and real external deliveries are excluded. Existing native builds cannot acquire a new pause notice remotely.

The experience uses the existing Hafa Homes logo, green/cream palette, readable typography, and one support action. No added motion is needed for a maintenance notice.
