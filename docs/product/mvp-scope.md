# MVP Scope

## Build target

The first version should be a **mobile-first PWA demo**.

It should look and feel like an app, but be accessible through a normal web link. This allows fast sharing with Mike, the investor, agents, and potential MLS/data partners.

## MVP principles

- Mobile-first, desktop-friendly
- Guam-first, not generic
- Demo with sample/seed listings before MLS access is finalized
- Build in a way that can support real MLS/IDX/API sync later
- Prioritize search, listing detail, lead capture, and local differentiation

## MVP screens

### 1. Home / search landing screen

Features:

- Hafa Homes branding
- Guam hero imagery
- Buy / Rent tabs
- Village/city selector
- Price, beds, baths filters
- Property type selector
- Quick search chips:
  - Near Andersen AFB
  - Near Navy Base
  - Near Camp Blaz
  - Pet friendly
  - Ocean view
  - Furnished rentals
  - Military/OHA friendly

### 2. Search results

Features:

- List view
- Map view or map/list split
- Listing cards
- Sort by newest, price, village, featured
- Filter drawer
- Save search CTA

### 3. Listing detail

Features:

- Photo gallery
- Price / rent
- Address / village
- Beds, baths, square footage
- Property type
- MLS number placeholder
- Status
- Description
- Feature badges:
  - Generator
  - Water tank
  - Typhoon shutters
  - Split AC
  - Fenced yard
  - Pet friendly
  - Furnished
  - Pool
  - Gated community
  - Ocean view
- Base proximity / commute estimate placeholder
- Contact / request showing CTA
- Save listing
- Share listing

### 4. Saved listings and searches

Features:

- Favorites
- Saved searches
- Alert frequency placeholder
- Email/SMS alert concept

### 5. Village/neighborhood pages

Example pages:

- Tamuning
- Tumon
- Dededo
- Yigo
- Mangilao
- Barrigada

Features:

- Overview
- Active listings
- Median price/rent placeholder
- Commute notes
- Lifestyle notes
- Nearby base/school notes

### 6. Military relocation page

Features:

- Search near Andersen AFB
- Search near Naval Base Guam
- Search near Camp Blaz
- Search near Naval Hospital
- PCS housing guide content
- OHA/rental explanation placeholder

### 7. Lead capture flows

Forms:

- Request showing
- Ask about property
- Get listing alerts
- Find a rental
- Sell my property
- Property manager/owner inquiry

### 8. Admin/data concept screen

For demo/investor confidence, include a simple admin/data sync concept:

- MLS sync status
- Last sync time
- Listings imported
- Listings updated
- Sync errors/review needed

This does not need to be fully functional in the demo, but it helps explain how daily MLS updates will work.

## MVP data

Initial demo can use sample Guam listings modeled after public listing patterns:

- Homes for sale
- Condos for sale
- Rentals
- Luxury property
- Military-friendly rental
- Pet-friendly rental
- Land/commercial example if needed

Important: sample data should be clearly marked as demo data unless authorized real listing data is provided.

## Out of scope for first demo

- Full MLS integration
- Native iOS/Android builds
- Payment processing
- Complex CRM
- Real-time chat
- Mortgage underwriting
- Legal rental applications
- Full property management system

## Success criteria

The MVP/demo is successful if Mike and the investor can say:

1. This clearly feels like a Guam version of Locations LLC.
2. This feels more polished than current Guam real estate websites.
3. The MLS integration path makes sense.
4. The product is worth moving into a funded build phase.
